# RP2040 Adaptation Notes

## Core Repository

| Platform | Repository | Notes |
|---|---|---|
| Arduino | `arduino/arduino-pico` | Official RP2040 Arduino core |
| PlatformIO | `platformio/raspberrypi` | Built-in platform |
| MicroPython | `micropython/ports/rp2` | Primary RP2040 port |

## PIO (Programmable I/O)

RP2040's key feature is two PIO state machines that can implement arbitrary protocols. For standard peripherals (SPI, I2C, UART), the Arduino core handles PIO setup automatically.

### Pin Constraints

Unlike ESP32's GPIO matrix, RP2040 has some **fixed-function pins**:

| Function | Pins | Notes |
|---|---|---|
| ADC | GPIO26-29 | Only these 4 pins have ADC, input-only |
| USB | GPIO0-1 (D+/D-) or GPIO12-13 (D+/D-) | Configured at board level |
| Crystal | GPIO12-13 (if using external) | Internal oscillator by default |

All other GPIOs (0-29 except ADC) are general-purpose and can be used for any peripheral.

## variant.h Specifics

```cpp
#include <Arduino.h>  // Arduino.h is fine for RP2040

#define BOARD_NAME "Seeed XIAO RP2040"
// ... standard defines
```

RP2040 core uses `pin_function` tables internally, not `PinDescription` arrays.

## MicroPython

- **Port**: `lib/micropython/ports/rp2` (CMake-based)
- **Config style**: CMake (`CMakeLists.txt`, `boards/<board>/`)
- **Pin naming**: `GPIOx` (e.g., `GPIO25`, `GPIO26`)
- **Flash**: UF2 drag-and-drop or picotool
- **Toolchain**: `arm-none-eabi-gcc`
- **Build**: `make BOARD=SEEED_XIAO_RP2040` in `ports/rp2`

XIAO RP2040 has well-established MicroPython support upstream.

| Method | Tool | Command |
|---|---|---|
| UF2 (USB mass storage) | Drag-and-drop | Hold BOOTSEL, connect USB, copy `.uf2` |
| picotool | `picotool` | `picotool load firmware.uf2` |
| SWD (OpenOCD) | `openocd` | `openocd -f interface/cmsis-dap.cfg -f target/rp2040.cfg ...` |

No external bootloader needed — RP2040 boots from flash or ROM USB bootloader.

## Build Notes

For PlatformIO, may need a custom `CMakeLists.txt` for board-specific build flags.

## Known Pitfalls

| Problem | Cause | Solution |
|---|---|---|
| ADC reads zero on GPIO0 | GPIO0-25 have no ADC | Use GPIO26-29 for ADC |
| USB not enumerated | Wrong GPIO for USB D+/D- | Check board USB pin config matches hardware |
| Boot loop | Bad UF2 or flash corruption | Hold BOOTSEL, reflash |
| PIO conflict | Two peripherals using same PIO | Distribute across PIO0 and PIO1 |
